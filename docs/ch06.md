# 范畴与函子

<div class="chapter-lede">范畴、函子与「函子保同构」——各不变量的统一语言。</div>

<div class="epigraph" markdown="1">

**「枢始得其环中，以应无穷。」**

—— 《庄子·齐物论》

</div>



!!! definition "定义 6.1（范畴）"

    一个**范畴** $C$ 包括以下要素：
    1. 对象类 $\operatorname{Ob}(C)$（可以是真类，不必是集合——例如"全体集合"不是集合）；
    2. 对任意两个对象 $X,Y$，指定集合 $\operatorname{Mor}(X,Y)$，元素称为**态射**，写作 $f:X\to Y$；
    3. 复合规则 $\operatorname{Mor}(X,Y)\times\operatorname{Mor}(Y,Z)\to\operatorname{Mor}(X,Z)$，$(f,g)\mapsto g\circ f$，
        满足：
    - 结合律：$(h\circ g)\circ f=h\circ(g\circ f)$；
    - 单位律：每个对象 $X$ 有 $\operatorname{id}_X$，使 $\forall f:X\to Y$，$g\circ\operatorname{id}_X=f$ 等。

!!! example "例 6.2（常见范畴）"

    集合范畴（集合，映射）；拓扑范畴（拓扑空间，连续映射）；群范畴（群，同态）；
    $F$-线性空间范畴（$F$-线性空间，线性映射）。

!!! definition "定义 6.3（（协变）函子）"

    范畴 $C$ 到 $D$ 的**协变函子** $F:C\to D$ 是一套对应：
    1. 对象层面：$X\mapsto F(X)\in\operatorname{Ob}(D)$；
    2. 态射层面：$f:X\to Y\ \mapsto\ F(f):F(X)\to F(Y)$，
        满足 $F(g)\circ F(f)=F(g\circ f)$（复合律）与 $F(\operatorname{id}_X)=\operatorname{id}_{F(X)}$（单位律）。

    （反序满足此二律者称**逆变函子**。）

!!! corollary "推论 6.4（函子保同构）"

    协变函子将同构的对象映成同构的对象。

!!! example "例 6.5（遗忘函子）"

    群范畴 $\to$ 集合范畴：$(G,\cdot)\mapsto G$，同态 $\mapsto$ 底映射（忽略运算结构）。

!!! remark "注 6.6（本课程的三大函子）"

    基本群与同调都是"拓扑范畴 $\to$ 群（Abel 群）范畴"的函子：

    \[
    \pi_1,\ H_n:\ \{\text{拓扑空间},\text{连续映射}\}\longrightarrow\{\text{群},\text{同态}\},
    \]

    其中 $H_n$ 通过链复形范畴分解：拓扑空间 $\mapsto$ 奇异链复形 $\xrightarrow{H_*}$ 分次 Abel 群。
    "**函子保同构**"（推论 6.4）正是"同胚/同伦等价的空间有同构的 $\pi_1$ 与 $H_n$"
    的范畴论表述——这也是本章存在的意义。
